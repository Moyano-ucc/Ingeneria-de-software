{% if lesson['id'] == 'variables' %}

1. ¿Qué es una variable?

Una variable es un nombre que permite guardar y consultar un valor durante la ejecución de un programa. Se crea asignándole un valor mediante el operador =.

nombre = "Ana"
edad = 20
altura = 1.65
estudia = True

print(nombre)
print(edad)
print(altura)
print(estudia)

2. Tipos de datos básicos

  • str: texto, por ejemplo "Hola".
  • int: números enteros, como 20.
  • float: números decimales, como 3.5.
  • bool: valores lógicos True y False.
ciudad = "Bogotá"
semestre = 6
promedio = 4.2
aprobado = True

print(type(ciudad))
print(type(semestre))
print(type(promedio))
print(type(aprobado))

La función type() permite consultar el tipo de dato de una variable. Python determina el tipo según el valor asignado.

3. Reglas para nombrar variables

Los nombres pueden contener letras, números y guiones bajos, pero no pueden comenzar con un número ni contener espacios. Es recomendable utilizar nombres descriptivos.

# Correcto
precio_producto = 15000
cantidad = 2
total = precio_producto * cantidad
print(total)

# Incorrecto: 2precio = 100
# Incorrecto: precio producto = 100

4. Cambiar el valor de una variable

Una variable puede recibir un nuevo valor durante la ejecución del programa.

puntos = 10
print(puntos)

puntos = 15
print(puntos)

puntos = puntos + 5
print(puntos)

La última instrucción utiliza el valor actual de puntos, le suma cinco y guarda el resultado nuevamente.

5. Mini reto

Imagina que debes calcular el costo de varios productos. ¿Qué variables necesitarías para guardar el precio, la cantidad y el total? Intenta escribir el programa antes de continuar.

precio = 4500
cantidad = 3
total = precio * cantidad

print("Total a pagar:", total)
{% elif lesson['id'] == 'operadores' %}

1. Operadores aritméticos

Permiten realizar operaciones matemáticas con valores numéricos.

print(3 + 4)    # 7
print(10 - 2)   # 8
print(3 * 5)    # 15
print(10 / 2)   # 5.0
print(9 // 2)   # 4
print(7 % 2)    # 1
print(2 ** 3)   # 8
  • +: suma.
  • -: resta.
  • *: multiplicación.
  • /: división, que puede producir decimales.
  • //: división entera.
  • %: residuo de una división.
  • **: potencia.

2. Operadores de comparación

Comparan dos valores y producen un resultado lógico: True o False.

edad = 20

print(edad > 18)   # True
print(edad == 20)  # True
print(edad != 15)  # True
print(edad < 18)   # False
print(edad >= 20)  # True
print(edad <= 17)  # False

Recuerda que = asigna un valor, mientras que == compara si dos valores son iguales.

3. Orden de las operaciones

Python sigue las reglas matemáticas de precedencia. Los paréntesis permiten indicar qué operación debe realizarse primero.

resultado = 2 + 3 * 4
otro = (2 + 3) * 4

print(resultado)  # 14
print(otro)       # 20

4. Operadores con variables

Los operadores se pueden combinar con variables para resolver situaciones cotidianas.

precio = 12000
cantidad = 3
subtotal = precio * cantidad
descuento = 5000
total = subtotal - descuento

print("Subtotal:", subtotal)
print("Descuento:", descuento)
print("Total:", total)

5. Mini reto

Calcula el promedio de tres notas y utiliza una comparación para comprobar si el resultado es mayor o igual a 3.0.

nota1 = 4.0
nota2 = 3.5
nota3 = 2.5

promedio = (nota1 + nota2 + nota3) / 3

print("Promedio:", promedio)
print("¿Aprobó?", promedio >= 3.0)
{% elif lesson['id'] == 'entrada_salida' %}

1. Mostrar información con print()

La función print() muestra texto, variables y resultados en la consola.

nombre = "Laura"
edad = 19

print("Hola")
print(nombre)
print("Edad:", edad)

2. Recibir información con input()

La función input() permite que una persona escriba un dato. El valor recibido inicialmente es texto, incluso cuando se escribe un número.

nombre = input("Escribe tu nombre: ")
print("Bienvenido,", nombre)

3. Convertir los datos recibidos

edad = int(input("Escribe tu edad: "))
altura = float(input("Escribe tu altura: "))

print("El próximo año tendrás", edad + 1)
print("Tu altura es", altura)

Utiliza int() para convertir a entero y float() para convertir a decimal. Si el texto no representa un número válido, la conversión puede producir un error.

4. Un ejemplo completo

producto = input("Producto: ")
precio = float(input("Precio: "))
cantidad = int(input("Cantidad: "))

total = precio * cantidad

print("Producto:", producto)
print("Total a pagar:", total)

5. ¿Qué diferencia hay entre entrada y salida?

La entrada permite recibir información del usuario; la salida permite mostrar información o resultados. En un programa pueden utilizarse varias veces.

{% elif lesson['id'] == 'repaso_fundamentos' %}

1. Combinar los fundamentos

En un programa podemos recibir datos, guardarlos en variables, convertirlos, operar con ellos y mostrar el resultado.

nombre = input("Nombre del estudiante: ")
nota1 = float(input("Primera nota: "))
nota2 = float(input("Segunda nota: "))
nota3 = float(input("Tercera nota: "))

promedio = (nota1 + nota2 + nota3) / 3

print("Estudiante:", nombre)
print("Promedio:", round(promedio, 2))

2. Analicemos el programa

  1. input() recibe el nombre.
  2. float() convierte las notas a números decimales.
  3. Las variables guardan los valores introducidos.
  4. Los operadores calculan el promedio.
  5. round() redondea el promedio a dos decimales.
  6. print() presenta el resultado.

3. Validar un resultado

promedio = 3.8
aprobado = promedio >= 3.0

print("Promedio:", promedio)
print("¿Aprobó?", aprobado)

4. Reto de repaso

Modifica el ejemplo para calcular el promedio de cuatro notas y mostrar el resultado con dos decimales.

{% elif lesson['id'] == 'conversion_datos' %}

1. ¿Por qué convertir datos?

En Python, los datos recibidos por input() son cadenas de texto. Para realizar operaciones matemáticas, normalmente debemos convertirlos al tipo adecuado.

numero_texto = "25"
numero_entero = int(numero_texto)
numero_decimal = float(numero_texto)
texto = str(numero_entero)

print(numero_entero + 5)  # 30
print(numero_decimal)    # 25.0
print(texto)             # 25

2. Conversiones comunes

  • int("12") produce el entero 12.
  • float("3.5") produce el decimal 3.5.
  • str(100) produce el texto "100".

3. Cuidado con los errores

edad = int("20")       # Correcto
precio = float("8.5")  # Correcto

# int("hola") produciría un ValueError

Antes de convertir un dato, comprueba que su contenido tenga el formato esperado.

4. Aplicación práctica

cantidad = int(input("Cantidad de productos: "))
precio = float(input("Precio por producto: "))

total = cantidad * precio
print("Total:", total)
{% elif lesson['id'] == 'cadenas_texto' %}

1. ¿Qué es una cadena?

Una cadena de texto es una secuencia de caracteres escrita normalmente entre comillas simples o dobles.

mensaje = "Hola, Python"
nombre = 'Camila'

print(mensaje)
print(nombre)

2. Unir cadenas

nombre = "Pedro"
saludo = "Hola, " + nombre

print(saludo)
print("Hola,", nombre)

Puedes unir cadenas con + o pasar varios valores a print(), que los separa por defecto con un espacio.

3. Métodos útiles

texto = "Aprender Python"

print(texto.lower())
print(texto.upper())
print(texto.title())
print(len(texto))

lower() convierte a minúsculas, upper() a mayúsculas, title() pone en mayúscula inicial las palabras y len() cuenta los caracteres.

4. Saltos de línea

print("Primera línea\nSegunda línea")

El carácter especial \n introduce un salto de línea dentro del texto.

5. Interpolación con f-strings

Una f-string permite insertar variables dentro de un texto usando llaves.

nombre = "Laura"
edad = 19

print(f"Hola, {nombre}. Tienes {edad} años.")
{% elif lesson['id'] == 'condicionales' %}

1. Tomar decisiones

Las estructuras condicionales permiten ejecutar instrucciones dependiendo de si una condición es verdadera o falsa.

edad = 20

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

La condición se escribe después de if y termina con dos puntos. El bloque debe tener la indentación correcta.

2. Usar elif

nota = 4.2

if nota >= 4.5:
    print("Excelente")
elif nota >= 3.0:
    print("Aprobaste")
else:
    print("Debes reforzar el tema")

elif permite evaluar otra condición cuando la anterior no se cumple. else cubre los casos restantes.

3. Condiciones con variables

saldo = 50000
compra = 35000

if saldo >= compra:
    print("Compra aprobada")
else:
    print("Saldo insuficiente")

4. Errores comunes

  • Olvidar los dos puntos al final de la condición.
  • Escribir el bloque sin la indentación necesaria.
  • Usar = cuando se quiere comparar con ==.
{% elif lesson['id'] == 'operadores_logicos' %}

1. Combinar condiciones

Los operadores lógicos permiten combinar o modificar condiciones para tomar decisiones más precisas.

  • and: ambas condiciones deben ser verdaderas.
  • or: basta con que una condición sea verdadera.
  • not: invierte el valor lógico.
edad = 20
tiene_documento = True

print(edad >= 18 and tiene_documento)
print(edad < 18 or tiene_documento)
print(not tiene_documento)

2. Aplicarlos en un programa

edad = int(input("Edad: "))
tiene_permiso = input("¿Tienes permiso? (si/no): ")

if edad >= 18 and tiene_permiso == "si":
    print("Puedes ingresar")
else:
    print("No cumples los requisitos")

Combinar condiciones permite comprobar varios requisitos antes de ejecutar una acción.

3. Practicar el razonamiento lógico

llueve = False
tengo_paraguas = True

if not llueve or tengo_paraguas:
    print("Puedo salir")
{% elif lesson['id'] == 'ciclo_for' %}

1. Repetir instrucciones

El ciclo for permite recorrer una secuencia de valores y ejecutar un bloque de código por cada elemento.

for numero in range(5):
    print(numero)

Este ejemplo imprime los números del 0 al 4. El límite final de range(5) no se incluye.

2. Definir un inicio y un final

for numero in range(1, 6):
    print(numero)

range(1, 6) comienza en 1 y llega hasta 5. También puedes especificar un paso.

for numero in range(0, 10, 2):
    print(numero)

3. Usar un acumulador

total = 0

for numero in range(1, 4):
    total = total + numero

print("Suma:", total)

La variable total acumula los valores de cada repetición. El resultado es 6.

4. Recorrer una lista

frutas = ["manzana", "pera", "uva"]

for fruta in frutas:
    print(fruta)
{% elif lesson['id'] == 'ciclo_while' %}

1. Repetir mientras se cumpla una condición

El ciclo while repite un bloque mientras su condición sea verdadera.

contador = 1

while contador <= 5:
    print(contador)
    contador += 1

El contador aumenta en cada repetición. Cuando llega a 6, la condición deja de cumplirse y el ciclo termina.

2. Usar break

contador = 0

while True:
    contador += 1
    print(contador)

    if contador == 3:
        break

break termina el ciclo inmediatamente. En este ejemplo, el programa se detiene cuando el contador llega a 3.

3. Evitar ciclos infinitos accidentales

Si la condición nunca cambia y continúa siendo verdadera, el ciclo puede no terminar. Actualiza las variables que intervienen en la condición o define una salida cuando sea apropiado.

4. Acumular valores

contador = 1
total = 0

while contador <= 3:
    total += contador
    contador += 1

print("Total:", total)

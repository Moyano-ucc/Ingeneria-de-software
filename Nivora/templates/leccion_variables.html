Variables y tipos de datos

Una variable es un nombre que usamos para guardar un valor y utilizarlo después.

Crear una variable

En Python usamos el signo = para guardar un valor:

nombre = "Ana"
edad = 20

Ahora nombre contiene un texto y edad contiene un número entero.

Tipos básicos

  • str: texto, por ejemplo "Hola".
  • int: números enteros, por ejemplo 10.
  • float: números decimales, por ejemplo 3.14.
  • bool: verdadero o falso, por ejemplo True.
